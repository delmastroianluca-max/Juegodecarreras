# Juegodecarreras
**Racing Simulator 2D** es un videojuego de automovilismo en 2D con vista superior que busca ofrecer una experiencia de competición realista y completa. Incluye cuatro categorías: Fórmula 1, GT, Rally y Turismo, con escuderías, pilotos, vehículos y circuitos inspirados en el automovilismo real. Cuenta con físicas de conducción, campeonatos
